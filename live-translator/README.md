# livesub: زیرنویس و ترجمه‌ی همزمان، رایگان و روی کامپیوتر خودت

`livesub` هر صدایی را که کامپیوتر پخش می‌کند (یوتیوب، لایو، پلیر فیلم، تماس تصویری) می‌گیرد،
با Whisper به متن تبدیل می‌کند، با یک مدل زبانی محلی ترجمه می‌کند و زیرنویس را در یک نوار شناور
روی همه‌ی پنجره‌ها نشان می‌دهد. همه‌چیز روی کارت گرافیک خودت اجرا می‌شود و هزینه‌ای ندارد.

دو حالت دارد:

| حالت | کاربرد | کیفیت |
|---|---|---|
| `live` | لایو یوتیوب و هر چیزی که الان پخش می‌شود | خوب، با حدود ۲ تا ۴ ثانیه تأخیر |
| `file` | فیلمی که روی هارد داری؛ یک فایل `.srt` فارسی می‌سازد | خیلی بهتر، چون عجله‌ای ندارد و از بزرگ‌ترین مدل استفاده می‌کند |

```
صدای سیستم → تشخیص مکث (Silero VAD) → گفتار به متن (faster-whisper) → ترجمه (Ollama) → نوار زیرنویس
```

## نصب (ویندوز و کارت گرافیک NVIDIA)

۱. **پایتون ۳.۱۰ تا ۳.۱۳** را از python.org نصب کن و موقع نصب تیک *Add python.exe to PATH* را بزن.

۲. **درایور کارت گرافیک** را به‌روز کن. نصب CUDA Toolkit لازم نیست، چون کتابخانه‌هایش با pip نصب می‌شوند.

۳. **Ollama** را از ollama.com نصب کن و مدل ترجمه را بگیر:

```bat
ollama pull aya-expanse:8b
```

> `aya-expanse` برای ۲۳ زبان، از جمله فارسی، آموزش دیده است. اگر کارت گرافیکت ۱۲ گیگ یا بیشتر حافظه دارد،
> `gemma3:12b` را هم امتحان کن و با `--ollama-model gemma3:12b` انتخابش کن. بعد هر کدام را که بهتر ترجمه کرد نگه دار.

۴. **خود برنامه:** داخل پوشه‌ی `live-translator` یک ترمینال (cmd) باز کن:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

۵. **(اختیاری) فونت وزیرمتن** را از github.com/rastikerdar/vazirmatn بگیر و نصب کن تا زیرنویس خواناتر شود.
اگر نصب نکنی، برنامه از Segoe UI استفاده می‌کند.

اولین اجرا مدل Whisper را دانلود می‌کند (حدود ۱.۵ گیگ برای `large-v3-turbo` و ۳ گیگ برای `large-v3`).

## استفاده

### زیرنویس زنده

```bat
python -m livesub live --lang en
```

یا روی `run-live.bat` دوبار کلیک کن. حالا هر ویدیویی را پخش کنی، زیرنویس فارسی‌اش پایین صفحه می‌آید.

- **جابه‌جا کردن نوار:** با ماوس بکش.
- **اندازه‌ی متن:** با چرخ ماوس.
- **نشان دادن یا پنهان کردن متن اصلی:** دوبار کلیک.
- **بستن:** کلیک راست یا Esc.

اگر زبان گوینده را می‌دانی، `--lang` را بده (مثلاً `en`، `de`، `tr`). هم دقیق‌تر است و هم سریع‌تر.
اگر ندهی، زبان خودکار تشخیص داده می‌شود.

### ساخت زیرنویس برای فیلم

```bat
python -m livesub file "D:\Movies\film.mkv" --lang en
```

خروجی، یعنی `film.fa.srt`، کنار فیلم ساخته می‌شود و VLC یا پلیرهای دیگر خودشان پیدایش می‌کنند.
با `--keep-source` زیرنویس زبان اصلی هم ساخته می‌شود.

### گزینه‌های مفید

| گزینه | توضیح |
|---|---|
| `--translator google` | به‌جای Ollama از گوگل ترنسلیت رایگان استفاده می‌کند. نصب چیزی لازم نیست، ولی اینترنت می‌خواهد و ترجمه‌اش ضعیف‌تر است |
| `--model large-v3` / `medium` / `small` | مدل Whisper. هرچه بزرگ‌تر باشد دقیق‌تر و کندتر است |
| `--compute-type float16` | کمی دقیق‌تر، ولی حافظه‌ی گرافیک بیشتری می‌خواهد (پیش‌فرض `int8_float16`) |
| `--max-chunk 6` | تأخیر کمتر وقتی گوینده بی‌وقفه حرف می‌زند، ولی جمله‌ها بیشتر بریده می‌شوند |
| `--speaker "Headphones"` | صدای یک خروجی دیگر را بگیرد. فهرست دستگاه‌ها: `python -m livesub devices` |
| `--mic "Microphone"` | به‌جای صدای سیستم، میکروفون را گوش کند |
| `--hide-source` | فقط ترجمه را نشان بدهد |
| `--no-overlay` | خروجی را در ترمینال چاپ کند |
| `--target en` | زبان مقصد را عوض کند (پیش‌فرض `fa`) |

همه‌ی گزینه‌ها: `python -m livesub live --help`

## حافظه‌ی کارت گرافیک

Whisper و Ollama هر دو روی کارت گرافیک اجرا می‌شوند:

| حافظه‌ی گرافیک | پیشنهاد |
|---|---|
| ۶ گیگ | `--model small` و `aya-expanse:8b`، یا `--translator google` |
| ۸ گیگ | پیش‌فرض‌ها (`large-v3-turbo` و `aya-expanse:8b`) |
| ۱۲ گیگ و بیشتر | `--compute-type float16` و `gemma3:12b` |

اگر حافظه کم بیاید، Ollama بخشی از مدل را روی CPU اجرا می‌کند و ترجمه کند می‌شود.

## مشکلات رایج

- **`Could not load library cudnn...` یا `cublas64_12.dll`:** دستور `pip install -r requirements.txt` را دوباره اجرا کن.
  اگر درست نشد، برای امتحان `--device cpu` را بزن (کند است، ولی نشان می‌دهد بقیه‌ی برنامه سالم است).
- **`Ollama is not reachable`:** برنامه‌ی Ollama باز نیست. از منوی استارت اجرایش کن.
- **هیچ زیرنویسی نمی‌آید:** با `--no-overlay` اجرا کن و ببین متن انگلیسی چاپ می‌شود یا نه.
  اگر نمی‌شود، با `python -m livesub devices` ببین صدا از کدام خروجی پخش می‌شود و آن را با `--speaker` بده.
- **جمله‌ها نصفه ترجمه می‌شوند:** طبیعی است که در حالت زنده گاهی پیش بیاید. برای فیلم از حالت `file` استفاده کن.
