# Order Blocks MTF + POC (5m … 4H) — اندیکاتور تریدینگ‌ویو

فایل: `order_blocks_poc.pine` (Pine Script v6). همه‌چیز در **یک اندیکاتور** است تا با محدودیت تعداد اندیکاتور در نسخه‌ی رایگان تریدینگ‌ویو مشکلی پیش نیاید.

## نصب
Pine Editor → کد را جایگزین کنید → Save → Add to chart.

## نمایش جداگانه‌ی تایم‌فریم‌ها
- **Mode = Selected TFs:** هر تایم (5m / 10m / 15m / 30m / 45m / 1H / 4H) تیک و رنگ صعودی/نزولی جداگانه دارد. پیش‌فرض: 15m، 1H و 4H روشن.
- **Mode = Single TF:** فقط یک تایم نمایش داده می‌شود.
- روی هر زون اسم تایم نوشته می‌شود (`1H ▲` صعودی، `1H ▼` نزولی).
- تایم‌های کوچک‌تر از تایم چارت نمایش داده نمی‌شوند.

## POC
- **POC داخل هر اردربلاک** (خط‌چین): قیمتی که بیشترین حجم داخل کندل اردربلاک معامله شده. از کندل‌های تایم چارت حساب می‌شود، پس تایم چارت باید کوچک‌تر از تایم اردربلاک باشد (مثلاً چارت 5m برای OB های 1H و 4H).
- **POC دوره‌ای (Day / Week / 4H):** POC دوره‌های قبل (خط ممتد) تا وقتی قیمت به آن نخورده ادامه پیدا می‌کند (Naked POC). تعداد قابل تنظیم.
- **Developing POC** (نقطه‌چین): POC دوره‌ی جاری که در حال شکل‌گیری است.

## سایر
- بدون ریپینت (فقط کندل‌های بسته‌شده).
- جدول اطلاعات، حذف زون‌های هم‌پوشان، آلارم اردربلاک جدید (*Any alert() function call*).
