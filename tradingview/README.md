# MTF Fair Value Gap Pro (Pine Script v6)

اندیکاتور FVG چندتایم‌فریمی برای TradingView که FVGهای **4H، 1H، 30m و 15m** رو روی یک چارت نشون میده.

## نصب
1. فایل `mtf_fvg.pine` رو باز کن و کل محتواش رو کپی کن.
2. در TradingView پنل **Pine Editor** رو باز کن، کد قبلی رو پاک کن و این کد رو Paste کن.
3. روی **Add to chart** بزن.
4. بهترین نتیجه رو روی چارت **۱۵ یا ۵ دقیقه** می‌گیری. تایم‌فریم‌های کوچک‌تر از تایم‌فریم چارت خودکار خاموش می‌شن (مثلاً روی چارت 1H، تایم‌های 30m و 15m رو Off می‌بینی).

## امکانات
| بخش | توضیح |
|---|---|
| تشخیص FVG | الگوی ۳ کندلی روی هر تایم‌فریم، فقط با کندل‌های **بسته‌شده**، پس ریپینت نداره |
| فیلتر ATR | حداقل اندازه‌ی گپ برابر `x × ATR` همون تایم‌فریم (پیش‌فرض 0.25) |
| فیلتر Displacement | بدنه‌ی کندل وسط باید حداقل ۵۰٪ رنجش باشه و هم‌جهت با گپ |
| خط CE | خط ۵۰٪ هر ناحیه |
| اولین برخورد | وقتی قیمت اولین بار به ناحیه می‌رسه، رنگ باکس کم‌رنگ‌تر می‌شه (FVG دست‌نخورده از FVG تست‌شده قابل تشخیصه) |
| ابطال | با Close (بسته شدن بدنه بیرون از ناحیه) یا Wick |
| IFVG | FVG شکسته‌شده به IFVG تبدیل می‌شه و نقشش برعکس می‌شه. اگه IFVG هم شکسته بشه، کامل حذف می‌شه |
| داشبورد | تعداد نواحی حمایتی/مقاومتی فعال در هر TF، وضعیت قیمت، و **Confluence** (قیمت هم‌زمان داخل ناحیه‌ی ۲ تایم‌فریم یا بیشتر) |

## هشدارها (Alerts)
روی چارت Alert بساز و Condition رو بذار روی **MTF FVG → Any alert() function call**.
هشدارها شامل این موارد هستن: تشکیل FVG جدید، اولین برخورد قیمت، تبدیل به IFVG و Confluence چندتایم‌فریمی. هر کدوم رو می‌تونی از تنظیمات خاموش کنی.

## رنگ‌بندی
تایم‌فریم بالاتر پررنگ‌تر نمایش داده می‌شه (4H پررنگ‌ترین و 15m کم‌رنگ‌ترین). روی هر باکس هم برچسب تایم‌فریمش نوشته شده (`4H FVG`، `1H IFVG` و ...).
