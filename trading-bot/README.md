# EmoTrader — ربات معامله‌گر با احساس ترس و طمع

رباتی که بازار را تحلیل می‌کند و مثل یک معامله‌گر واقعی **می‌ترسد و طمع می‌کند** —
و شما تعیین می‌کنید این احساسات چقدر روی تصمیمش اثر بگذارند.

> ⚠️ این پروژه آموزشی است و توصیه‌ی مالی نیست. ربات فقط تحلیل، شبیه‌سازی و بک‌تست
> می‌کند و هیچ سفارش واقعی به صرافی نمی‌فرستد.

## نصب و اجرا

```bash
cd trading-bot
pip install -r requirements.txt          # فقط numpy و pandas

python -m emotrader analyze              # تحلیل آخرین کندل + حال ربات + تصمیم
python -m emotrader backtest --personality emotional --save-log log.csv
python -m emotrader compare              # مقایسه‌ی همه‌ی شخصیت‌ها
python -m unittest discover -s tests     # تست‌ها
```

منبع داده:

| گزینه | توضیح |
|---|---|
| (هیچ) | بازار مصنوعی با فاز صعود، نزول، رنج، سقوط و حباب (`--seed` برای تغییر) |
| `--csv data.csv` | ستون‌های `time, open, high, low, close` و `volume` (اختیاری) |
| `--exchange binance --symbol BTC/USDT --timeframe 4h` | داده‌ی عمومی صرافی، بدون کلید API (`pip install ccxt`) |

## ربات چطور فکر می‌کند؟

```
داده‌ی بازار ─► تحلیل‌گر ─► امتیاز سیگنال (-۱ … +۱)  ─┐
                    └──► شاخص ترس و طمع بازار (۰…۱۰۰) ─┼─► موتور احساسات ─► ترس، طمع ─┐
           نتیجه‌ی معاملات خود ربات (سود/ضرر، افت سرمایه) ─┘                            │
                                                         تصمیم: خرید / فروش / صبر  ◄────┘
```

### ۱. تحلیل‌گر بازار (`analyzer.py`)
- **روند:** EMA20 در برابر EMA50
- **مومنتوم:** هیستوگرام MACD
- **اشباع:** RSI و باندهای بولینگر
- **نوسان:** ATR و نسبت نوسان فعلی به نوسان عادی

خروجی: یک امتیاز بین ۱- و ۱+، و یک **شاخص ترس و طمع بازار** (شبیه شاخص CNN) که از
نوسان، افت از سقف، فاصله از میانگین، RSI و حجم معاملات ساخته می‌شود.

### ۲. موتور احساسات (`emotions.py`)
ربات دو منبع احساس دارد:
- **سرایت از بازار:** وقتی بازار می‌ترسد، ربات هم می‌ترسد. ربات «خلاف‌جهت» برعکس عمل
  می‌کند: «وقتی دیگران می‌ترسند طمع کن، وقتی طمع می‌کنند بترس.»
- **تجربه‌ی شخصی:** ضرر ← شوک ترس، بُردهای پشت‌سرهم ← طمع، افت سرمایه ← اضطراب،
  سود روی پوزیشن باز ← وسوسه‌ی ماندن.

احساسات **حافظه** دارند و به‌تدریج فروکش می‌کنند. حالت‌ها: وحشت‌زده 😱، ترسیده 😨،
محتاط 😟، آرام 😐، مشتاق 🙂، طمع‌کار 😏، سرمست/FOMO 🤑.

### ۳. اثر احساسات بر تصمیم (`trader.py`)

| | ترس | طمع |
|---|---|---|
| آستانه‌ی ورود | سخت‌گیرتر | آسان‌تر (FOMO) |
| حجم معامله | کمتر | بیشتر |
| حد ضرر | تنگ‌تر | شل‌تر |
| حد سود | زودتر سیو می‌کند | بیشتر نگه می‌دارد |
| رفتار خاص | فروش هیجانی وقتی در ضرر است | دیرتر خارج می‌شود |

پارامتر **انضباط** (`discipline`) شدت این اثر را تعیین می‌کند: ۱ یعنی ربات بی‌احساس، ۰ یعنی کاملاً احساسی.

### شخصیت‌های آماده

| نام | ویژگی |
|---|---|
| `robot` | بی‌احساس، مبنای مقایسه |
| `balanced` | احساس دارد ولی منضبط است |
| `emotional` | احساسی، پیرو جمع، اهل فروش هیجانی |
| `buffett` | خلاف‌جهت، در ترس بازار فرصت می‌بیند |
| `coward` | خیلی ترسو، حجم کم، خروج زود |

شخصیت دلخواه بسازید:

```python
from emotrader import EmotionalTrader, Personality
from emotrader.data import load_csv

me = Personality("من", fear_sensitivity=1.2, greed_sensitivity=0.8, discipline=0.5, contrarian=0.6)
result = EmotionalTrader(me).backtest(load_csv("btc.csv"))
print(result.total_return, result.max_drawdown, result.last_decision.notes)
```

## مدیریت ریسک
- ریسک هر معامله ۱٪ سرمایه (قابل تغییر در `RiskConfig`)، بدون اهرم
- حد ضرر و حد سود بر اساس ATR
- اجرای سفارش در قیمت باز کندل بعد، با کارمزد و لغزش قیمت — بدون نگاه به آینده
- فقط پوزیشن خرید (long)

## نتایج واقعی تست
میانگین روی ۲۰ بازار مصنوعی (هر کدام ۱۰۰۰ کندل): همه‌ی شخصیت‌ها بازده کوچکِ مثبت
(حدود ۲ تا ۵٪) با افت سرمایه‌ی کم (۵ تا ۷٪) داشتند، اما **خرید و نگهداری ساده با میانه‌ی
حدود ۲۲٪ بهتر بود** (با ریسک بسیار بیشتر). ربات احساسی بیشترین افت سرمایه و تنها ربات با
فروش هیجانی بود. یعنی این ربات یک پایه‌ی آموزشی و آزمایشگاهی است، نه ماشین پول‌سازی.
قبل از هر استفاده‌ی واقعی، روی داده‌ی واقعی بک‌تست کنید.
