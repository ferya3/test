# EmoTrader برای متاتریدر ۵

اکسپرت (Expert Advisor) با احساس ترس و طمع. روی متاتریدر ۵ و با **قیمت زنده‌ی بروکر شما**
اجرا می‌شود. پیش‌فرض برای طلا (XAUUSD) در تایم‌فریم ۵ دقیقه تنظیم شده است.

> ⚠️ حالت پیش‌فرض **فقط تحلیل** است و هیچ سفارشی نمی‌فرستد. قبل از معامله‌ی خودکار، حتماً
> در Strategy Tester و روی حساب دمو تستش کنید. این توصیه‌ی مالی نیست.

## نصب
1. متاتریدر ۵ را باز کنید ← منوی **File ← Open Data Folder**.
2. فایل `EmoTrader.mq5` را در پوشه‌ی `MQL5\Experts` کپی کنید.
3. **F4** را بزنید تا MetaEditor باز شود. در پنل Navigator فایل `EmoTrader.mq5` را باز کنید
   و **F7** (Compile) را بزنید. باید `0 errors` ببینید.
4. در متاتریدر، چارت طلا را باز کنید (اسمش بسته به بروکر `XAUUSD`، `GOLD` یا `XAUUSD.m` است).
5. از پنل Navigator ← Expert Advisors، گزینه‌ی **EmoTrader** را روی چارت بکشید.
6. در تب Common تیک **Allow Algo Trading** را بزنید. دکمه‌ی **Algo Trading** بالای متاتریدر هم باید سبز باشد.

پنل تحلیل گوشه‌ی بالا-چپ چارت ظاهر می‌شود و با هر تیک به‌روز می‌شود.

## تنظیمات مهم (Inputs)
| تنظیم | توضیح |
|---|---|
| Mode | `Analyze only` = فقط سیگنال و هشدار؛ `Auto trade` = معامله‌ی خودکار |
| Personality | Robot، Balanced، Emotional، Contrarian (بافت)، Coward، Custom |
| Analysis timeframe | پیش‌فرض M5؛ مستقل از تایم‌فریم چارت |
| Risk per trade | درصد سرمایه که با خوردن حد ضرر از دست می‌رود (پیش‌فرض ۰.۵٪) |
| Stop loss / Take profit | بر اساس ATR (پیش‌فرض ۲ و ۳ برابر ATR) |
| Max spread | اگر اسپرد بیشتر از ۰.۲۵ ATR باشد وارد نمی‌شود (مثلاً موقع رول‌اور شبانه) |
| Max trades per day / Daily loss | سقف معاملات روزانه و توقف بعد از ۳٪ ضرر روزانه |
| Push notification | ارسال سیگنال به گوشی (MetaQuotes ID را در Tools ← Options ← Notifications وارد کنید) |

## اثر احساسات
- **ترس:** آستانه‌ی ورود بالاتر، حجم کمتر، حد ضرر و حد سود نزدیک‌تر. در حالت وحشت، پوزیشن
  ضررده را می‌بندد (فقط وقتی انضباط پایین باشد).
- **طمع:** ورود راحت‌تر (FOMO)، حجم بیشتر، حد سود دورتر، نگه داشتن طولانی‌تر.
- **منبع احساسات:** ترس و طمع بازار (نوسان، فاصله از سقف، فاصله از میانگین، RSI، حجم تیک)،
  به‌اضافه‌ی نتیجه‌ی معاملات خود ربات (ضرر و سود پشت‌سرهم، افت سرمایه، سود یا ضرر پوزیشن باز).
- **Discipline:** ۱ یعنی کاملاً بی‌احساس، ۰ یعنی کاملاً احساسی.

## بک‌تست با داده‌ی واقعی
**Ctrl+R** ← Expert: `EmoTrader` ← Symbol: طلا ← Period: M5 ←
Modelling: **Every tick based on real ticks** ← بازه‌ی تاریخ ← **Start**.
برای مقایسه، یک بار هم با Personality = Robot اجرا کنید تا ببینید احساسات کمک کرده‌اند یا ضرر زده‌اند.
