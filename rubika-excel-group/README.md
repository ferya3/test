# Rubika Excel Group

افزونهٔ مرورگر (Chrome / Edge, Manifest V3) برای **روبیکا وب** که مخاطبین را از یک
فایل اکسل می‌خواند، آن‌ها را به دفترچهٔ حساب شما اضافه می‌کند و یک گروه با همان افراد
می‌سازد.

A browser extension for **Rubika Web** that reads contacts from an Excel file,
adds them to your account's address book, and creates a group containing them.

> فقط روی حساب خودتان کار می‌کند؛ `auth` و کلید خصوصی از خودتان گرفته می‌شود و هیچ
> چیزی جایی بیرون از روبیکا فرستاده نمی‌شود.
>
> Works only on your own account. Your `auth` and private key stay in the page and
> are used solely to sign your own requests to Rubika — nothing is sent anywhere else.

## نصب / Install

1. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
2. **Load unpacked** را بزنید و پوشهٔ `rubika-excel-group` را انتخاب کنید.
3. در تب `https://web.rubika.ir` وارد حساب شوید، سپس روی آیکون افزونه کلیک کنید تا
   پنل باز شود.

## استفاده / Use

1. `auth` (۳۲ کاراکتر) و کلید خصوصی حساب را وارد کنید. اگر روبیکا وب آن‌ها را در
   حافظهٔ مرورگر نگه داشته باشد، خودکار پیش‌پر می‌شوند.
2. فایل اکسل را انتخاب کنید. یک ستون برای **شماره** و (اختیاری) ستون‌هایی برای
   **نام** و **نام خانوادگی** کافی است — سرستون‌های فارسی یا انگلیسی شناسایی
   می‌شوند، و اگر سرستونی نباشد ستونی که بیشترین شمارهٔ معتبر را دارد انتخاب می‌شود.
3. نام گروه را بنویسید و **ساخت گروه** را بزنید.

شماره‌های ایران در شکل‌های `09…`, `+98…`, `0098…`, `98…` و با ارقام فارسی پشتیبانی
می‌شوند و به صورت `98XXXXXXXXXX` نرمال می‌شوند. فقط شماره‌هایی که حساب روبیکا دارند
به گروه اضافه می‌شوند؛ بقیه در گزارش علامت می‌خورند.

## نحوهٔ کار / How it works

| فایل | نقش |
| --- | --- |
| `manifest.json` | تعریف افزونه و دسترسی به `web.rubika.ir` و سرورهای `*.iranlms.ir` |
| `background.js` | تزریق پنل با کلیک روی آیکون؛ بازپخش درخواست‌ها اگر صفحه با CORS روبه‌رو شود |
| `src/crypto.js` | رمزنگاری API نسخهٔ ۶ روبیکا: AES-256-CBC، امضای RSA، و تبدیل auth |
| `src/session.js` | ساختن نشست امضا از `auth` + کلید خصوصی و تأیید با `getUserInfo` |
| `src/api.js` | کلاینت API: یافتن دیتاسنتر، فراخوانی رمزگذاری‌شده، failover و back-off |
| `src/excel.js` | خواندن اکسل با SheetJS و نرمال‌سازی شماره‌ها |
| `src/panel.js` | رابط کاربری درون‌صفحه‌ای |
| `lib/xlsx.full.min.js` | کتابخانهٔ SheetJS (Apache-2.0) |

روش رمزنگاری از کلاینت‌های متن‌بازِ موجود روبیکا (rubpy / pyrubi / arsein) گرفته شده
و در `tests/` بایت‌به‌بایت با خروجی پایتونِ آن‌ها مقایسه می‌شود.

## تست / Test

```bash
npm test
```

`tests/vectors.json` با کلید RSA یکبارمصرف توسط rubpy ساخته شده تا رمزنگاری مرورگر
با پیاده‌سازی مرجع تطبیق داده شود.

## محدودیت‌ها / Notes

- API روبیکا رسمی و مستند نیست؛ اگر روبیکا پروتکل را عوض کند ممکن است نیاز به
  به‌روزرسانی باشد (مثلاً `app_version` در `src/api.js`).
- افزودن مخاطب با فاصلهٔ کوتاه بین درخواست‌ها انجام می‌شود تا به محدودیت نرخ نخورد.
  برای لیست‌های خیلی بزرگ، کمی صبر کنید.
