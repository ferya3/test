# Excel Group (Rubika & Eitaa)

افزونهٔ مرورگر (Chrome / Edge, Manifest V3) برای **روبیکا وب** و **ایتا وب** که
مخاطبین را از یک فایل اکسل می‌خواند، آن‌ها را به مخاطبین حساب شما اضافه می‌کند و یک
گروه با همان افراد می‌سازد.

A browser extension for **Rubika Web** and **Eitaa Web** that reads contacts from
an Excel file, adds them to your account's contacts, and creates a group with them.

## نصب / Install

1. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
2. **Load unpacked** را بزنید و پوشهٔ `excel-group` را انتخاب کنید.
3. در `https://web.rubika.ir` یا `https://web.eitaa.com` وارد حساب شوید، سپس روی
   آیکون افزونه کلیک کنید تا پنل باز شود.

## استفاده / Use

1. **روبیکا:** `auth` و کلید خصوصی حساب را وارد کنید (در صورت وجود از حافظهٔ مرورگر
   پیش‌پر می‌شوند).
   **ایتا:** چیزی لازم نیست؛ افزونه از همان نشستی که در ایتا وب وارد شده‌اید استفاده
   می‌کند.
2. فایل اکسل را انتخاب کنید. یک ستون **شماره** و (اختیاری) ستون‌های **نام** و
   **نام خانوادگی** کافی است. سرستون‌های فارسی یا انگلیسی شناسایی می‌شوند و اگر
   سرستونی نباشد، ستونی که بیشترین شمارهٔ معتبر را دارد انتخاب می‌شود.
3. نام گروه را بنویسید و **ساخت گروه** را بزنید.

شماره‌های ایران در شکل‌های `09…`، `+98…`، `0098…`، `98…` و با ارقام فارسی پشتیبانی
می‌شوند. فقط شماره‌هایی که حساب دارند به گروه اضافه می‌شوند؛ بقیه در لاگ پنل نوشته
می‌شوند، همین‌طور کسانی که تنظیمات حریم خصوصی‌شان اجازهٔ افزودن نمی‌دهد.

## نحوهٔ کار / How it works

| فایل | نقش |
| --- | --- |
| `manifest.json` | تعریف افزونه و دسترسی به دو سایت و سرورهای API روبیکا |
| `background.js` | تزریق پنل با کلیک روی آیکون؛ بازپخش درخواست‌های روبیکا در صورت خطای CORS |
| `src/panel.js` | رابط کاربری درون‌صفحه‌ای (مشترک) |
| `src/excel.js` | خواندن اکسل با SheetJS و نرمال‌سازی شماره‌ها (مشترک) |
| `src/backends.js` | منطق هر پیام‌رسان با یک رابط یکسان |
| `src/crypto.js`، `src/session.js`، `src/api.js` | روبیکا: رمزنگاری و کلاینت API نسخهٔ ۶ |
| `src/eitaa-bridge.js` | ایتا: اجرا در خود صفحه و صدا زدن مدیرهای داخلی ایتا وب |
| `lib/xlsx.full.min.js` | کتابخانهٔ SheetJS (Apache-2.0) |

**روبیکا:** روش رمزنگاری از کلاینت‌های متن‌باز روبیکا (rubpy / pyrubi / arsein) گرفته
شده و در `tests/` بایت‌به‌بایت با خروجی پایتون rubpy مقایسه می‌شود.

**ایتا:** ایتا وب بر پایهٔ Telegram WebK ساخته شده که `rootScope` را روی `window`
می‌گذارد. افزونه از `rootScope.managers` برای `importContact`، `createChat` و
`addChatUser` استفاده می‌کند، یعنی همان کارهایی که خود برنامه انجام می‌دهد، با نشست
فعلی شما.

## محدودیت‌ها / Notes

- هیچ‌کدام از این دو API رسمی و مستند نیست. اگر روبیکا یا ایتا نسخهٔ وب خود را عوض
  کنند، ممکن است افزونه نیاز به به‌روزرسانی داشته باشد.
- بخش ایتا با کد منبع Telegram WebK سنجیده شده، نه با خود ایتا وب. اگر پنل پیام
  «به داخل ایتا وب دسترسی پیدا نشد» داد، یعنی ایتا این بخش را تغییر داده است.
- گروه ایتا یک گروه معمولی است و حداکثر ۲۰۰ عضو می‌گیرد.
- بین افزودن هر مخاطب کمی مکث هست تا به محدودیت سرعت نخورد. ایتا اگر لازم باشد
  پیام انتظار می‌دهد و افزونه خودش صبر می‌کند و دوباره تلاش می‌کند.
