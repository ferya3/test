# vitaQueen — صفحه‌ی «در حال بروزرسانی»

یک صفحه‌ی تک‌فایل که مستقیم از یک Cloudflare Worker سرو می‌شود.
بدون build، بدون npm، بدون فایل جانبی — کافیست `worker.js` را در ادیتور کلادفلر paste کنید.

- دو عکس جدا برای دسکتاپ و موبایل
- شماره‌ی تماس به‌صورت دکمه؛ روی گوشی با یک لمس شماره‌گیری می‌شود
- چیدمان ریسپانسیو: روی صفحه‌ی افقی عکس تمام‌صفحه و متن رویش؛ روی گوشی عکس بالای صفحه و متن زیرش
- اگر عکسی ست نشود، گرادیان آبی برند نمایش داده می‌شود
- RTL، هدرهای امنیتی (CSP)، مسیرهای `/health` و `/robots.txt`

## راه‌اندازی از داشبورد کلادفلر

1. **Workers & Pages → Create → Workers → Start with Hello World → Deploy**
2. روی **Edit code** بزنید، کل محتوای `worker.js` را کپی و جای‌گذاری کنید
3. بالای فایل، بخش `CONFIG` را پر کنید
4. **Deploy**

## تنظیمات (`CONFIG` در بالای `worker.js`)

| کلید | توضیح |
| --- | --- |
| `SITE_NAME` | فقط در عنوان تب مرورگر و متا تگ‌ها استفاده می‌شود |
| `HEADLINE` | تیتر اصلی — `سایت در حال بروزرسانی می‌باشد` |
| `CONTACT_TEXT` | متن زیر تیتر — `جهت تماس با مدیر فروش…` |
| `PHONE` | شماره‌ای که روی دکمه نمایش داده می‌شود |
| `COUNTRY_CODE` | پیش‌شماره‌ی کشور برای لینک تماس (پیش‌فرض `+98`) |
| `BG_URL` | عکس دسکتاپ (افقی)، لینک **https** |
| `BG_URL_MOBILE` | عکس موبایل (عمودی)، لینک **https** — خالی = همان عکس دسکتاپ |
| `DIR` / `LANG` | `rtl`/`ltr` و کد زبان |

رنگ‌ها در ثابت `BRAND` (طلایی، آبی) قابل تغییرند.

هر کدام از این کلیدها را می‌توانید به‌جای ویرایش کد، در
**Settings → Variables and Secrets** هم تعریف کنید؛ متغیر محیطی بر `CONFIG` اولویت دارد.

## دکمه‌ی تماس

شماره‌ی `PHONE` خودکار به شکل بین‌المللی تبدیل و در `tel:` گذاشته می‌شود:

```
09149677100  →  tel:+989149677100
```

روی گوشی، لمس دکمه شماره‌گیر را با همان شماره باز می‌کند. ارتفاع دکمه ۶۰ پیکسل است
تا لمس کردنش راحت باشد.

## دو عکس: دسکتاپ و موبایل

انتخاب عکس با `<picture>` انجام می‌شود و دقیقاً با همان شرطی عوض می‌شود که چیدمان تغییر می‌کند:

- **صفحه‌ی افقی** (دسکتاپ، لپ‌تاپ، گوشی خوابیده) → `BG_URL`، تمام‌صفحه با `object-fit: cover`، متن رویش
- **صفحه‌ی عمودی** (گوشی، تبلت ایستاده) → `BG_URL_MOBILE`، بالای صفحه، پایینش در گرادیان محو می‌شود و متن زیرش می‌آید

پیشنهاد اندازه: دسکتاپ حدود ۱۹۲۰×۱۰۸۰ و موبایل حدود ۱۰۸۰×۱۶۰۰ (نسبت عمودی).
هر دو را زیر ۲۰۰ کیلوبایت فشرده کنید (WebP یا JPEG کیفیت ۸۰).

## عکس‌ها را کجا آپلود کنیم؟

هر دو لینک باید **https** باشند:

- **R2**: یک bucket بسازید، آپلود کنید و public access را روشن کنید
- **Cloudflare Images**: آپلود کنید و لینک delivery را بردارید
- هر هاست دیگری که لینک مستقیم https می‌دهد

## وصل‌کردن دامنه

دامنه باید در همان اکانت کلادفلر باشد (nameserverها به کلادفلر اشاره کنند). سپس:

**Workers & Pages → ورکر شما → Settings → Domains & Routes → Add → Custom domain**

رکورد DNS خودکار ساخته می‌شود؛ نیازی به ساختن دستی A یا CNAME نیست.

## اجرای محلی (اختیاری)

```bash
npm install
npm run dev      # http://localhost:8787
npm run deploy
```
