# vitaQueen — صفحه‌ی «به‌زودی»

یک لندینگ‌پیج تک‌فایل که مستقیم از یک Cloudflare Worker سرو می‌شود.
بدون build، بدون npm، بدون فایل جانبی — کافیست `worker.js` را در ادیتور کلادفلر paste کنید.

- عکس بک‌گراند تمام‌صفحه با لایه‌ی تیره تا متن روی هر عکسی خوانا بماند
- اگر عکس ست نشده باشد، گرادیان آبی برند نمایش داده می‌شود
- لوگوی متنی (تاج + vitaQueen) یا تصویر لوگوی خودتان
- شمارش معکوس اختیاری تا لحظه‌ی راه‌اندازی
- ریسپانسیو، RTL، هدرهای امنیتی (CSP با nonce)
- مسیرهای `/health` و `/robots.txt`

## راه‌اندازی از داشبورد کلادفلر

1. **Workers & Pages → Create → Workers → Start with Hello World → Deploy**
2. روی **Edit code** بزنید، کل محتوای فایل `worker.js` را کپی و جای‌گذاری کنید
3. بالای فایل، بخش `CONFIG` را پر کنید (پایین‌تر توضیح داده شده)
4. **Deploy**

## تنظیمات (`CONFIG` در بالای `worker.js`)

| کلید | توضیح |
| --- | --- |
| `SITE_NAME` | نام برند — تیتر اصلی |
| `SLOGAN` | شعار زیر تیتر، مثل `PURE LIFE, NATURAL CHOICE` |
| `BADGE` | متن نشان کوچک، مثل `به‌زودی` |
| `DESCRIPTION` | توضیح یک‌خطی (در متا تگ‌ها هم استفاده می‌شود) |
| `BG_URL` | لینک **https** عکس بک‌گراند — خالی = گرادیان پیش‌فرض |
| `BG_URL_MOBILE` | نسخه‌ی کراپ‌شده‌ی عمودی برای موبایل — خالی = همان عکس دسکتاپ |
| `BG_FIT` | `cover` (تمام‌صفحه، لبه‌ها کراپ می‌شوند) یا `contain` (کل عکس دیده می‌شود) |
| `BG_POSITION` | نقطه‌ی کراپ روی دسکتاپ: `center`، `top`، `left center`، `70% 40%` … |
| `BG_POSITION_MOBILE` | نقطه‌ی کراپ روی موبایل — خالی = مثل دسکتاپ |
| `SHOW_BRANDING` | اگر خود عکس لوگو و شعار دارد، `false` کنید تا تکراری نشود |
| `LOGO_URL` | لینک **https** لوگو — خالی = لوگوی متنی با تاج |
| `LAUNCH_DATE` | تاریخ ISO مثل `2026-12-01T09:00:00Z` — خالی = بدون شمارش معکوس |
| `CONTACT_EMAIL` | خالی = بدون لینک تماس |
| `DIR` / `LANG` | `rtl`/`ltr` و کد زبان |

رنگ‌های برند در ثابت `BRAND` (طلایی و آبی) قابل تغییرند.

هر کدام از این کلیدها را می‌توانید به‌جای ویرایش کد، در
**Settings → Variables and Secrets** هم تعریف کنید؛ متغیر محیطی بر `CONFIG` اولویت دارد.

## عکس بک‌گراند را کجا بگذاریم؟

`BG_URL` باید یک آدرس https باشد. ساده‌ترین گزینه‌ها:

- **R2**: یک bucket بسازید، عکس را آپلود کنید و public access را روشن کنید
- **Cloudflare Images**: آپلود کنید و لینک delivery را بردارید
- هر هاست دیگری که لینک مستقیم https می‌دهد

پیشنهاد: عکس را تا حدود ۲۰۰ کیلوبایت فشرده کنید (WebP یا JPEG با کیفیت ۸۰) تا صفحه سریع باز شود.

## تنظیم نمایش عکس

عکس به‌صورت `<img>` با `object-fit` رندر می‌شود، نه `background-attachment: fixed`
(که روی موبایل باگ دارد و عکس را بیش از حد بزرگ می‌کند).

یک عکس افقی روی صفحه‌ی عمودی گوشی ناچار کراپ می‌شود. سه راه برای کنترلش:

- **`BG_POSITION_MOBILE`** — تعیین کنید کدام قسمت عکس در کادر بماند.
  مثلاً اگر سوژه سمت چپ عکس است: `"left center"`
- **`BG_URL_MOBILE`** — بهترین کیفیت: یک کراپ عمودی (مثلاً ۹:۱۶) از همان عکس بسازید
  و لینکش را اینجا بدهید. زیر ۶۴۰ پیکسل عرض، این نسخه لود می‌شود.
- **`BG_FIT: "contain"`** — کل عکس دیده می‌شود و اطرافش با نسخه‌ی بلورشده‌ی خودش پر می‌شود.
  روی موبایل عکس به بالای صفحه می‌رود و متن زیرش می‌نشیند.

اگر عکس بک‌گراند خودش لوگو و شعار دارد، `SHOW_BRANDING` را `false` کنید تا لوگو دوتا نشود.

## وصل‌کردن دامنه

دامنه باید در همان اکانت کلادفلر باشد (nameserverها به کلادفلر اشاره کنند). سپس:

**Workers & Pages → ورکر شما → Settings → Domains & Routes → Add → Custom domain**

رکورد DNS خودکار ساخته می‌شود؛ نیازی به ساختن دستی A یا CNAME نیست.

## اجرای محلی (اختیاری)

اگر ترجیح می‌دهید با CLI کار کنید، `wrangler.jsonc` هم در ریپو هست:

```bash
npm install
npm run dev      # http://localhost:8787
npm run deploy
```
