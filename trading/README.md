# اندیکاتور RBR / DBD برای تایم ۴ ساعته

اندیکاتور `rbr-dbd-4h.pine` الگوهای ادامه‌دهندهٔ عرضه و تقاضا را روی چارت پیدا می‌کند:

- **RBR** (Rally – Base – Rally): یک کندل صعودی قوی، چند کندل بیس، و یک کندل صعودی قوی دیگر → ناحیهٔ **تقاضا**
- **DBD** (Drop – Base – Drop): یک کندل نزولی قوی، چند کندل بیس، و یک کندل نزولی قوی دیگر → ناحیهٔ **عرضه**

## نصب

۱. در تریدینگ‌ویو پایین صفحه **Pine Editor** را باز کنید.
۲. محتوای فایل `rbr-dbd-4h.pine` را کامل کپی و در ادیتور جای‌گذاری کنید.
۳. روی **Save** و سپس **Add to chart** بزنید.
۴. تایم‌فریم چارت را روی **4H** بگذارید. اگر روی تایم دیگری باشید، اندیکاتور یک برچسب هشدار نشان می‌دهد و چیزی رسم نمی‌کند (این قفل در تنظیمات قابل خاموش‌کردن است).

## منطق تشخیص

هر کندل دقیقاً یکی از این دو حالت است (تعریف‌ها با هم هم‌پوشانی ندارند):

| نوع | شرط |
|---|---|
| کندل موج (Leg) | بدنه ≥ ۵۵٪ کل کندل **و** رنج ≥ ۱× ATR |
| کندل بیس (Base) | بدنه ≤ ۴۵٪ کل کندل **و** رنج ≤ ۱× ATR |

الگو وقتی ثبت می‌شود که کندل بستهٔ فعلی یک موج خروجی باشد، پشت آن ۱ تا ۵ کندل بیس، و پشتِ آن‌ها یک موج ورودی هم‌جهت. علاوه بر این:

- موج خروجی باید بالای (یا زیرِ) کل بیس **بسته** شود.
- رنج موج خروجی باید حداقل به اندازهٔ رنج بیس باشد.

## ناحیه‌ها

- **خط پروگزیمال** (نزدیک به قیمت): به‌صورت پیش‌فرض از بدنهٔ کندل‌های بیس گرفته می‌شود؛ در تنظیمات می‌توانید آن را روی سایه (`Wicks`) بگذارید.
- **خط دیستال** (دور از قیمت): همیشه انتهای سایهٔ بیس است — یعنی جای منطقی حد ضرر.
- ناحیه تا زمانی که قیمت از آن رد نشده به سمت راست ادامه پیدا می‌کند.
- اولین برخورد قیمت با پروگزیمال، کادر را **خط‌چین** می‌کند (یعنی دیگر fresh نیست).
- بسته‌شدن قیمت آن‌سوی دیستال یعنی ناحیه **شکسته** شده و حذف می‌شود (یا خاکستری می‌ماند، اگر گزینه‌اش را روشن کنید).

## امتیاز کیفیت

عدد کنار برچسب `RBR`/`DBD` یک امتیاز ۰ تا ۱۰۰ است:

- ۴۰ امتیاز برای قدرت خروج از بیس (نسبت به ATR)
- ۳۰ امتیاز برای فشردگی بیس
- ۳۰ امتیاز برای کم‌بودن تعداد کندل‌های بیس

با نگه‌داشتن ماوس روی برچسب، تعداد کندل بیس و قیمت دقیق پروگزیمال/دیستال را می‌بینید.

## هشدارها (Alerts)

سه رویداد alert می‌فرستند: تشکیل ناحیهٔ جدید، برخورد قیمت با ناحیه، و شکسته‌شدن ناحیه. برای دریافت هر سه، هنگام ساخت alert گزینهٔ **Any alert() function call** را انتخاب کنید. برای اینکه فقط از تشکیل ناحیهٔ جدید خبردار شوید، از شرط‌های آمادهٔ `New RBR demand zone` یا `New DBD supply zone` استفاده کنید.

## تنظیم بر اساس بازار

- بازار پرنوسان (کریپتو): `Leg: min range (× ATR)` را ببرید روی ۱.۲ تا ۱.۵ تا فقط موج‌های واقعی شمرده شوند.
- بازار آرام (جفت‌ارزها): همان مقدار را روی ۰.۸ بیاورید.
- اگر ناحیه‌ها خیلی زیاد شدند: `Max base candles` را کم کنید یا `Leg-out range ≥ × base range` را بالاتر ببرید.

نکته: مقدار `Base: max body / range` همیشه به‌صورت خودکار کمی پایین‌تر از `Leg: min body / range` نگه داشته می‌شود تا یک کندل نتواند هم‌زمان موج و بیس باشد.
