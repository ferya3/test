# اندیکاتور RBR / DBD برای تایم ۴ ساعته

اندیکاتور `rbr-dbd-4h.pine` الگوهای ادامه‌دهندهٔ عرضه و تقاضا را روی چارت پیدا می‌کند:

- **RBR** (Rally – Base – Rally): موج صعودی، چند کندل بیس، موج صعودی دوم → ناحیهٔ **تقاضا**
- **DBD** (Drop – Base – Drop): موج نزولی، چند کندل بیس، موج نزولی دوم → ناحیهٔ **عرضه**

## نصب

۱. در تریدینگ‌ویو **Pine Editor** را باز کنید.
۲. کل محتوای `rbr-dbd-4h.pine` را کپی و جای‌گذاری کنید.
۳. **Save** و بعد **Add to chart**.
۴. تایم‌فریم چارت را روی **4H** بگذارید (وگرنه برچسب هشدار می‌بینید؛ این قفل در تنظیمات خاموش می‌شود).

## منطق تشخیص

کندل موج (Leg) با معیار مطلق سنجیده می‌شود، ولی کندل بیس **نسبت به همان دو موجِ کنارش**:

| بخش | شرط |
|---|---|
| موج ورودی/خروجی | بدنه ≥ ۵۵٪ کل کندل **و** رنج ≥ ۱× ATR *کندل قبل* |
| هر کندل بیس | بدنه ≤ ۵۰٪ بدنهٔ موجِ کوچک‌تر **و** رنج ≤ ۱× رنج موجِ کوچک‌تر |
| کل بیس | فاصلهٔ سقف تا کف بیس ≤ ۱× رنج موجِ کوچک‌تر |
| اتصال | کلوز موج ورودی و اوپن موج خروجی باید داخل محدودهٔ بیس باشند (بدون گپ) |
| خروج | موج خروجی باید بیرون از کل بیس **بسته** شود |

چرا نسبی؟ چون با آستانهٔ ثابت، هر کندلی که وسط دو حد می‌افتاد نه موج حساب می‌شد نه بیس، و کل الگو رد می‌شد. با معیار نسبی، «کوچک بودن» بیس نسبت به موج‌های اطرافش سنجیده می‌شود و الگو هم در بازار آرام و هم در بازار پرنوسان پیدا می‌شود.

ATR همیشه از **کندل قبل** خوانده می‌شود تا یک کندل انفجاری، آستانهٔ خودش را بالا نبرد.

## تنظیم دقت

پارامتر **Strictness** چهار آستانه را با هم جابه‌جا می‌کند:

| حالت | کِی؟ |
|---|---|
| `Loose` | ناحیه‌ها کم‌اند و الگوهای واضح را رد می‌کند |
| `Normal` | پیش‌فرض |
| `Strict` | چارت شلوغ است و ناحیه‌های بی‌کیفیت زیاد است |
| `Custom` | چهار آستانه را دستی در گروه *Custom thresholds* تنظیم می‌کنید |

جدول کوچک گوشهٔ چارت تعداد ناحیه‌های زنده و کل الگوهای پیداشده را نشان می‌دهد؛ با آن می‌شود عددی تنظیم کرد به‌جای حدس زدن.

## ناحیه‌ها

- **پروگزیمال** (نزدیک قیمت): پیش‌فرض از بدنهٔ کندل‌های بیس؛ قابل تغییر به سایه.
- **دیستال** (دور از قیمت): همیشه انتهای سایهٔ بیس — جای منطقی حد ضرر.
- ناحیه تا وقتی قیمت از دیستال رد نشده به راست ادامه می‌یابد.
- اولین برخورد با پروگزیمال → کادر خط‌چین می‌شود (دیگر fresh نیست).
- بسته‌شدن آن‌سوی دیستال → ناحیه شکسته و حذف می‌شود.
- ناحیهٔ جدیدی که بیش از ۶۰٪ داخل یک ناحیهٔ دست‌نخوردهٔ هم‌جهت باشد رسم نمی‌شود (سطح تکراری). با `Skip a zone overlapping…` قابل تنظیم است؛ روی ۱ یعنی همه رسم شوند.

## امتیاز کیفیت

عدد کنار برچسب، امتیاز ۰ تا ۱۰۰ است:

- ۴۰ امتیاز قدرت خروج از بیس
- ۴۰ امتیاز فشردگی بیس
- ۲۰ امتیاز کم‌بودن تعداد کندل‌های بیس

ناحیه‌های زیر حد نصاب (`Min zone score`) اصلاً رسم نمی‌شوند. با نگه‌داشتن ماوس روی برچسب، تعداد کندل بیس و قیمت پروگزیمال/دیستال را می‌بینید.

## هشدارها

سه رویداد alert می‌دهند: تشکیل ناحیهٔ جدید، برخورد، و شکست. برای هر سه، موقع ساخت alert گزینهٔ **Any alert() function call** را بزنید. برای فقط ناحیهٔ جدید، از شرط‌های آمادهٔ `New RBR demand zone` / `New DBD supply zone` استفاده کنید.
